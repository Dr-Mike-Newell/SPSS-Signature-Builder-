How do I add this to Outlook?
  1. Click “Copy my signature” above.
  2. In New Outlook or Outlook on the web, open Settings → Accounts → Signatures. In classic Outlook, use File → Options → Mail → Signatures.
  3. Paste the signature into the editor and save.
  4. Send yourself a test email, ideally to an external address, to check the links and images.
