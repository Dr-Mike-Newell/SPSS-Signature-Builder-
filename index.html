OUTLOOK-FRIENDLY

Using your signature

  1. Enter your details, select a signature format and choose any relevant logos.
  2. For marketing claims, select Promotional, then choose up to three and reorder them with the arrow buttons.
  3. Choose Copy for Outlook, then paste into Outlook's signature editor and save.
  4. Send a test email to an external recipient to check the images and spacing.

New Outlook and Outlook on the web: Settings > Accounts > Signatures. Classic Outlook (Windows): File > Options > Mail > Signatures. Menu names may vary.

Images in exported signatures use HTTPS URLs hosted on this repository's GitHub Pages site. GitHub Pages must be enabled before the logos can load for recipients. Logos added later should retain their filenames.
