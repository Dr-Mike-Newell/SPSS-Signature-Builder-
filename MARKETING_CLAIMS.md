## Asset handling

The high-resolution (2048 × 2048) University marketing artwork has been supplied as reference files by the requester. The builder uses their text statistics in the existing standard red-and-black email-safe format. The original graphics are deliberately not embedded into the email signature, as they are large square promotional images unsuited to Outlook signature stacking.

Image filenames are referenced in `config.js` under `sourceAsset` for traceability. The original binary images are not yet stored in this GitHub repository. They should only be added to an `assets/marketing-originals/` folder if needed for a future marketing asset gallery, retaining original colours, resolution and attribution.
